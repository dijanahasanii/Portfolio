Featured Project

AI-Powered Code Review Assistant

Bachelor Thesis · AI · Developer Tools · Code Analysis

My Bachelor thesis: a GitHub-integrated platform that analyzes repositories, surfaces structured code quality findings, and presents them in a real-time developer dashboard.

Problem

Manual reviews are inconsistent and slow. Teams need automated feedback in their GitHub workflow — without relying on expensive continuous AI API calls.

Solution

A full-stack assistant using static/heuristic analysis today, with an architecture designed for future integration of real AI models and APIs when cost and product needs allow.

My contribution

End-to-end ownership: React dashboard, Node.js/Express backend, GitHub OAuth & webhooks, Supabase persistence, Socket.IO live updates, and Railway deployment.

  • GitHub OAuth + repository connection
  • Webhook-triggered analysis pipeline
  • Structured findings with severity scores
  • Real-time review dashboard
  • Review history & run detail views
