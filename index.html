Bachelor’s Thesis · Featured Project

AI-Powered Code Review Assistant

A GitHub pull request can trigger an automated review, with live progress and findings in a React dashboard.

For my bachelor’s thesis, I built the GitHub integration, the Node.js review pipeline, and the React dashboard. The project brings rule-based feedback into a pull request workflow so developers can see what was flagged and where.

Trigger

A GitHub webhook queues a review when a pull request is opened, updated with new commits, or reopened.

Analyze

The engine checks supported source files at the relevant commit against predefined patterns. If it can’t scan that snapshot, it checks the changed lines instead.

Review

The dashboard shows live progress and organizes findings by file, line, and severity. Developers can also look back at past runs.

  • GitHub sign-in and repository access through OAuth 2.0
  • Static checks for patterns such as leftover debug output and possible hard-coded secrets
  • Review history in Supabase and live updates through Socket.IO
