Bachelor Thesis · Featured System

AI-Powered Code Review Assistant

Automated repository inspection platform, static heuristic rule engine, and real-time developer review dashboard.

Bachelor thesis project: an automated code review and repository inspection system that connects to GitHub, evaluates codebases using a snapshot static rule engine and heuristic checks, and broadcasts structured feedback to a live developer dashboard.

Problem

Manual code reviews are bottlenecked and inconsistent. Teams need fast, automated quality and security feedback in their workflow without incurring high recurring API costs or latency on every commit.

Architecture & Rules Engine

Engineered a full-stack platform using Node.js/Express and React. To maintain speed and cost predictability, the analysis engine parses Git repository snapshots and executes weighted static rules across tracked files, with diff heuristic fallbacks. The system is designed so live LLM analysis can be integrated as an external provider.

Full-Stack Implementation

Built the end-to-end stack: GitHub OAuth 2.0 authentication, webhook event pipelines, queue abstraction (in-process with Bull/Redis support), Supabase PostgreSQL persistence, Socket.IO live progress streaming, and a targeted auto-remediation service for safe code annotations and fixes.

  • GitHub OAuth 2.0 + webhook-driven repository ingestion
  • Git tree snapshot traversal & static heuristic rule checks
  • Categorized findings with severity & quality scoring
  • Targeted automated remediation engine for safe code fixes
  • Real-time progress and review results via Socket.IO
  • Review run history & issue tracking stored in Supabase
