AI-Powered Code Review Assistant

A GitHub-integrated platform that analyzes repositories, surfaces structured code quality findings, and presents them in a real-time developer dashboard — designed for AI-assisted developer workflows.

Overview

This is my Bachelor thesis project. It connects to GitHub, analyzes source code on push events, and shows structured review feedback in a live dashboard. The current implementation uses static/heuristic analysis because continuous AI API usage has cost considerations. The architecture is intentionally designed so real AI models/APIs can be integrated later.

The Problem

Manual code reviews are inconsistent and hard to scale. Teams need automated quality feedback inside their GitHub workflow — without depending on expensive continuous LLM calls for every push.

The Solution

A full-stack assistant that authenticates with GitHub, connects repositories, runs analysis through a backend pipeline, persists results, and streams updates to a React dashboard via Socket.IO.

My Role

End-to-end ownership across frontend, backend, authentication, webhooks, persistence, live updates, and production deployment on Railway.

Key Features

  • GitHub OAuth authentication
  • Repository connection and webhook-triggered analysis
  • Static/heuristic code analysis with severity scoring
  • Real-time review dashboard
  • Review history and detailed run views

Screenshots

Challenges

  • Balancing AI ambition with practical API cost constraints
  • Keeping analysis useful without continuous LLM calls
  • Integrating OAuth, webhooks, queues, and live UI into one coherent product

Results

Deployed thesis product with GitHub integration, review dashboards, and a clear path for future AI model integration.

Future Improvements

Deeper LLM integration for richer review suggestions, pull request comments, and broader language support.
