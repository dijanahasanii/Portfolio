Wandr

A travel experience platform built with a microservices architecture — Docker Compose services, MongoDB, React frontend, and notifications for shared travel posts.

Overview

Wandr is a multi-user travel blogging platform where people can publish experiences with photos, location data, and social engagement features.

The Problem

Travelers needed a centralized place to share location-tagged experiences and interact with posts — beyond a simple single-service CRUD app.

The Solution

A Docker Compose microservices architecture with Node.js services, shared MongoDB, and a React frontend for posting travel stories and receiving notifications.

My Role

Full Stack Developer — service design, frontend development, Docker configuration, and API work.

Key Features

  • User accounts and profiles
  • Photo uploads with captions
  • Location selection
  • Real-time notifications
  • Containerized microservices with Docker Compose

Architecture

Multiple Node.js services run behind Docker Compose with shared MongoDB. The React frontend communicates with backend services through API patterns suitable for a multi-service setup.

Challenges

  • Splitting functionality across services without over-complicating local development
  • Coordinating Docker Compose services and shared data access

Results

A working travel platform prototype that demonstrates microservices thinking, containerization, and full-stack delivery.
