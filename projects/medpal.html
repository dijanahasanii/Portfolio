MedPal

A digital health management platform for clinics, doctors, and patients — with role-based dashboards, appointments, and patient records.

Overview

MedPal is a full-stack web application that helps healthcare stakeholders manage patients, doctors, and appointments in one place instead of fragmented tools.

The Problem

Clinics needed a unified system for patient management and scheduling without switching between disconnected workflows.

The Solution

A React frontend with a Node.js/Express REST API and MongoDB, delivering authenticated role-based dashboards for admins, doctors, and patients.

My Role

Full Stack Developer — UI design, frontend architecture, API integration, authentication flows, and database modeling.

Key Features

  • Role-based authentication for admins, doctors, and patients
  • Appointment scheduling
  • Patient records management
  • Reusable React component library
  • Responsive dashboards

Challenges

  • Modeling role-based access across shared health workflows
  • Keeping dashboards consistent while serving different user roles

Results

A working full-stack health management application with authenticated role-based access and a demoable UI.
